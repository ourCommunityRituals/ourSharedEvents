# Interview Template — Bar / Taproom / Pub Owner

**Copy this file** for each conversation. Name it `INTERVIEW-NN-YYYY-MM-DD.md` where NN is the conversation number in the current discovery sprint.

Fill it out **within 30 minutes of the conversation ending**, while memory is sharp.

**Anonymize at write time.** Use venue type / neighborhood / role. Do NOT record names, specific addresses, or anything that could re-identify the conversation.
