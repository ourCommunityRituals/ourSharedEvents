# OCR vision (pointer)

The org vision lives in one place: `docs/OCR_VISION.md` in the OCR-docs repo. If it is not written there, it does not exist at the org level.

This file is the fourth governance file for ourSharedEvents (`CLAUDE.md`, `README.md`, `SKILL.md`, and this one). It holds no org facts of its own, so it cannot drift from the source.

- Org source: `OCR-docs/docs/OCR_VISION.md`
- Copy propagated into this repo: `.ocr-standards/docs/OCR_VISION.md`
- What OSE itself must hold, and its owner decisions: `AGENTS.md`
- Why a decision was made: `docs/adr/README.md`

When the org source and this repo disagree, code and tests win, then the ADR, then this pointer is updated. Do not paste vision text here.
