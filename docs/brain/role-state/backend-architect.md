Away from a seam the cell is the point's cell. Coordinates sent with an event carry no precision, so they are taken as placed. `geo.ts` keeps `location_type`, `viewport` and `bounds`. The address is never stored or logged; the one `EVENT_CELL_CHOICE` log line carries only the seam decision, the precision and the candidate count. **Not done:** no stored row was re-tagged. Rows written before the merge keep their old res-7 cell until a re-tag story with its own approval; PR #1493 gives the read-only SQL to count them. The address rule is proven only at the mock layer (Google stubbed); staging proves the parent rule.
