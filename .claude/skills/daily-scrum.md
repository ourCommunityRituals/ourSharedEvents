# Skill: Daily Scrum Check-In

## When to Use
User says: "scrum", "standup", "check in", "what's the status", "daily"

## Steps

1. Read `STORIES.md` for current sprint state
2. Read `.claude/inputs/` for any new intake items
3. Check recent git log for completed work
4. Report:
   - **Done**: Stories/tasks completed since last check-in
   - **In Progress**: What's actively being worked
   - **Next Up**: Next story by priority (respecting prerequisites)
   - **Blockers**: Anything preventing progress
5. Ask if user wants to start the next story or adjust priorities
