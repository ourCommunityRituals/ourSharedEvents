# Skill: Cross-Device Sync Status

## When to Use
User asks about sync, what's changed, or checks from a new device

## Steps

1. Check `git log --oneline -10` for recent changes
2. Check `.claude/inputs/` for unprocessed intake items
3. Check `STORIES.md` for any status changes
4. Check `.claude/sync/LINEAR-MAP.md` for sprint updates
5. Report what's new since the user's last session
6. Flag any conflicts or items needing attention
