# Story intake

1. Read new or changed files in `.claude/inputs/`.
2. For each item:
   - Write acceptance criteria in the format in `docs/brain/STORY-FORMAT.md`.
   - Find prerequisites among existing Linear stories (team OSE).
   - Decide the phase or epic it belongs to.
3. Search Linear for duplicates before creating anything. Show the owner the drafted stories, and create them in Linear only after a yes.
4. Record the new ids in `.claude/sync/LINEAR-MAP.md` if that map is still in use.
