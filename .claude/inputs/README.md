# Inputs — Story Intake

Drop `YYYY-MM-DD-short-description.md` files here from any device.
Claude picks these up during daily scrum and adds them to STORIES.md.

## Template

```markdown
# [Story Title]

## Type
epic | feature | story | bug | chore

## Priority
high | medium | low

## Description
What needs to happen and why.

## Acceptance Criteria
- [ ] Criterion 1
- [ ] Criterion 2
```
